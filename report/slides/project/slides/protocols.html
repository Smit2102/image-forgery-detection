Smit Patel · EDS 6364 · 6 · balanced accuracy, 5-fold grouped CV on the development set

Restricting to JPEGs (C) does not help: quantisation tables still leak. Re-encoding once (B) removes the metadata shortcut, but compression-history statistics survive. Resampling before re-encoding (R) erases most of it; what remains is mainly image size. The split is also leakage-safe: images sharing a source, exact duplicates and verified near-duplicates stay in the same split. The test set was frozen before any model was trained.
