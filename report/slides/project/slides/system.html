A tool that explains every verdict

  • Analyze an image: verdict, suspected region, all eight evidence maps
  • Why this verdict: per-image SHAP attributions in plain language
  • PDF and JSON reports, mask and overlay downloads
  • Batch mode for a folder of photos
  • Dataset explorer and results dashboard

About 0.2 s per typical image, on a laptop and fully offline. The held-out test images are never listed in the explorer.
